# 方案三：三杆扇形斜拱桥，中央吊钩净空版

本版为 84 件，外形 510 × 64.5 × 98 mm。所有木条仍为 2.5 × 2.5 mm 方木。中央预留 20 × 20 mm 从桥底到桥顶的贯通通道，模型、逐件下料表和 STEP/GLB 使用同一份真实几何。

这是保留原有裁判口径争议的方案。斜坡上的三根主杆略呈扇形、相距很近；本次留孔不改变这个性质，不能因为精确平行杆的距离检查通过就把整体标成无争议方案。

## 本次到底改了什么

原先 x = 255 的中央冠部横杆挡住吊钩。现在冠部四根 H 分列在 x = 221.5、243、267、288.5；K1 只在 221.5～243，K2 只在 267～288.5，中间不再跨杆。

为了让新增横杆仍装进 12 根原料，桥总宽从 66.5 减到 64.5，两片侧架各向内平移 1 mm。全部 58 件侧架木条 C/A/B/R/S/T/V 的形状、x/z 位置及彼此搭接保持不变；只有空间联系杆 H/I/K 随新宽度重新裁切。主杆仍高 98，没有把木条截面缩细。

旧版 83 件文件已保存在 archive-before-hook/。不能把旧版下料表或横杆长度混用于本版。

## 如何认位置

所有坐标单位是毫米。x 从左桥端向右，y 从近侧向远侧，z 从桥底向上。桥中线 x = 255，桥底 z = 0，最高平面 z = 98。右坡坐标 x右 = 510 − x左。

| 零件层 | 近侧中心 y | 远侧中心 y |
|---|---:|---:|
| A/B/R/S/T 主体层 | −28.5 | +28.5 |
| 三根 C 外层主杆 | −31.0 | +31.0 |
| V 内层冠部斜撑 | −26.0 | +26.0 |

C 的内侧面与主体层外侧面相贴；V 的外侧面与 B/T 内侧面相贴。相邻层是侧面搭接，不是木条实体穿插。网页拆开视图只为看清层位，实际木面要贴实。

左坡三根 C 的轴线脚点 x = 25、40、51，顶点 x = 219、226、233，分别从 z = 0 到 98。每根 C 上下端都沿水平线平切，不能沿斜杆垂直方切。右坡镜像。三种 C 下料长度不同，按各自编号取料。

左坡 R/H 的四站 x = 77.2、114.4、151.6、188.8；相应横杆 H 中心高 z = 19.6、39.2、58.8、78.4。不同位置 R 的长短不同，不能把全部 R 切成一种长度。左右、近远同站对应件互为镜像。

A 每侧一根完整 510，不拼接。B 每侧终长 89，x = 210.5～299.5，顶面 z = 98。T 在 x = 255，底 z = 76.5、顶 z = 95.5，终长 19；V 在相邻内层侧贴 B/T。T/V 虽在正视图里靠中央，但它们的 y 坐标在两侧，不能移到桥中心。

标准 H 终长 54.5；两个脚部 Hf 终长 59.5，中心位于 x = 40 / 470、z = 3.75，下表面放在 A 上。冠部 H 顶面与 B、C 顶面齐平 z = 98。

## 吊钩通道

x = 245～265、y = −10～+10 的 20 × 20 区域，从 z = 0 到 98 完全没有木材。实际名义通槽为 21.5 × 49.5，所需 20 方盒与最近木面留 0.75。该尺寸已经逐个真实实体与贯穿盒做布尔检查。

20 × 20 是暂定净空，并不是量过吊钩后得到的尺寸。拿到实际加载器后应确认吊钩能顺畅通过，不得让补杆或胶块进入通道。吊钩不贴桥，也不作为额外结构支撑。

## 下料与装配

先按 12 根原料分配表给每件写编号，再从原料切毛坯，最后按坐标修端。每件表中的“成品轴向包络长”是实体顶点沿杆轴的最大投影减最小投影，包含斜切尖端；“毛坯长”再加修配余量。轴线两定位点的距离不能拿来替代下料长度。

C 两端水平切。S/I/K/V 按各自 x 拼缝平面斜切，不能插入相邻横杆或竖箍；必要的顶部角砂到 z = 98，不能冒出顶面。普通 R/H/T 按表定长方切。不同零件不要凭屏幕上看起来差不多就互换。

先平放做好两片侧架，再用脚部、冠部和中间 H 定宽，随后补齐 I/K。不断检查桥底平、桥顶齐、两侧平行；开缝接头应修端重贴，不能用大胶团当填料。按胶瓶说明等到充分固化后再轻载排错。

## 哪些地方涂胶

232 处真实正面积接触中，228 处是有效涂胶节点；另外 4 处 K/B 仅为约 0.0883 mm² 的偶然角点擦触，明确保持干接触，不涂胶、不计承力连接。K1 两端只贴 Hc1/Hc2 下表面，K2 两端只贴 Hc3/Hc4 下表面。排除这些微角后，全部 84 件仍通过有效胶接连成一个整体。

每处胶只涂在实际交叠面与 7.0 × 2.5 标记矩形的交集里，标记外保持干接触。全模型沿任何相接木条轴向的胶斑最大投影 7.4329，小于规则 8。两端标记只是画出的涂胶范围，不是另加胶带。3 g 胶需要薄涂，建议留少量补救；胶面积不能直接换算成保证强度。

## 材料与放置核对

- 84 件毛坯共 6529.0，加每件 0.5 切耗共 42.0，总计 6571.0；12 根 550 已逐根排下，仅余 29.0 零头。余量很紧，不要先随意下料。
- 木材名义实体体积 39.5455 cm³。如果按 3 g 胶全部留在成品计，木材密度需不高于约 0.48046 g/cm³ 才能满足 22 g。木种、实际尺寸和留胶量未确认，最终必须称桥，不能凭模型保证重量。
- 支台内缘 x = 55 / 455，净跨 400；桥两端各外伸 55。所有 C 底端的完整端面都在支台内，最小裕量约 1.36。
- 80 方加载板中心对准 x = 255、y = 0，板边 x = 215 / 295、y = −40 / +40；所有 C 顶端完整落在板内，最小边缘裕量约 1.23，放板必须仔细居中。

84 个 OCCT 实体有效；3486 对零件无体积穿插；STEP 回读仍 84 件，GLB 每件闭合且体积匹配实体。几何正确不等于实物强度已认证，尤其要验证偏心搭接、薄胶质量和底弦传力。新结构的承重分析必须使用本版真实接头与加载方式，不能沿用旧 83 件的数值。
