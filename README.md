# 木桥搭建参考

纯静态 3D 搭建参考，模型和脚本均内嵌在 `index.html`。可旋转、切换三视角、隐藏构件组、分解观察、按件号选择木条。

默认显示方案一，页首按以下顺序切换：

1. **方案一：合规方案** — 原双侧桁架桥。
2. **方案二：双杆格构** — 平行压杆真正留出至少10毫米净距，配三角支撑与空间连接。
3. **方案三：争议方案** — 三杆扇形斜拱，依赖近似平行杆的裁判解释；始终排在最后。

各方案使用自己的模型、下料资料和分析说明。顶部数值如有显示，均为带明确假设的理论计算参考，不能当成实测承重或承重保证，也不能跨分析口径直接排名。页面不设人为的目标重量。

## 方案一资料

- `files/bridge-drawings.pdf`：E2搭建图纸。
- `files/bridge-kit.zip`：图纸、离线查看器、GLB、STEP、搭建说明与开源许可。
- `files/bridge-model.glb`、`files/bridge-model.step`：交换格式模型。
- `files/read-first.txt`：搭建与打印说明。

这套PDF和离线资料包仅对应方案一，不用于其他方案。

## 方案二资料

- `files/bridge-lattice-model.glb`、`files/bridge-lattice-model.step`：双杆格构交换格式模型。
- `files/bridge-lattice-read-first.txt`：完整搭建说明。
- 网页提供91件毛坯和终切说明、12根原料排料及215处胶区定位；实际使用11根，第12根整根备用。
- 本方案按明确的杆间净距、禁止平行叠粘和胶接长度条文设计；名义模型审核不替代实物测量。

## 方案三资料

- `files/bridge-v2-model.glb`、`files/bridge-v2-model.step`：原扇形斜拱模型；为保持下载兼容，文件名保留v2。
- 原83件实体、下料表和12根排料保持独立，不与方案二混用。

全部木条截面为2.5 × 2.5毫米，原料为12根、每根550毫米，胶水限3克。屏幕图像不是1:1定位模板；轴线端点距离不等于毛坯长度。透明承压板和支架仅表示比赛器具，不计入木材或导出模型。

模型不包含胶厚与手工误差。实际承重取决于木材、胶水、接头、支承接触和制作质量；22克限重必须实称，排料满足原料总长不等于成品重量合格。
