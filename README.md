# 木桥搭建参考

纯静态 3D 搭建参考，模型和脚本均内嵌在 `index.html`。可旋转、切换三视角、隐藏构件组、分解观察、按件号选择木条。

默认显示方案1（双杆格构），页首按以下顺序切换：

1. **方案1：双杆格构** — 90 mm高，平行压杆名义净距约10.52毫米。
2. **方案2：双侧桁架桥** — 95 mm高，顶面和底面都绕开中央通道。
3. **方案3：三杆扇形斜拱（一中争议方案）** — 98 mm高，依赖近似平行杆的裁判解释；始终排在最后。

三个当前版本均已检查：桥中心x=255、y=0预留20 × 20毫米上下贯通净空。网页标签展示与当前实体和胶接数据绑定的最新计算值，不沿用留孔前的数字。

标签中的公斤数为带明确假设的理想弹性失稳载荷当量，不能当成实测承重或承重保证，也不能跨分析口径直接排名。各方案使用自己的模型、下料资料和分析说明。页面不设人为的目标重量。

## 方案1资料（双杆格构，90 mm／中央留孔版）

- `files/bridge-lattice-90mm-model.glb`、`files/bridge-lattice-90mm-model.step`：双杆格构交换格式模型。
- `files/bridge-lattice-90mm-read-first.txt`：完整搭建说明。
- 网页提供92件木条的修好后长度、毛坯与终切说明、12根原料排料及216处有效胶区定位；实际使用11根，第12根整根备用。
- 全桥长510、宽60.5、高90毫米；模型显示总尺寸线，可按选中木条、构件组或全部显示长度标签。修好后长度按实体沿木条轴向的最远两端计算，不等于轴线端点距。
- 中央横杆和冠部斜撑已移至通道两侧；20 × 20毫米是暂定吊钩所需净空，实际吊钩尺寸仍需量取核对。名义开口约21.5 × 45.5毫米。
- 本方案按明确的杆间净距、禁止平行叠粘和胶接长度条文设计；名义模型审核不替代实物测量。请勿混用旧98毫米版模型、下料表和计算说明。

## 方案2资料（双侧桁架，中央留孔版）

- `files/bridge-v1-hook-model.glb`、`files/bridge-v1-hook-model.step`：当前58件交换模型。
- `files/bridge-v1-hook-read-first.txt`：搭建说明和逐件下料、排料表。
- 总长510、总宽73.5、总高95毫米。新增顶/底各两根横杆，两个原跨中斜撑改为四根短斜撑，中央上下对齐留空。
- 128处有效胶接。12根原料含切耗用6145毫米，剩455毫米。

旧52件模型的PDF和ZIP保留为历史文件，但已从当前网页移除链接，不能据其制作本版。

## 方案3资料（一中争议方案）

- `files/bridge-v2-hook-model.glb`、`files/bridge-v2-hook-model.step`：当前84件交换模型。
- `files/bridge-v2-hook-read-first.txt`：搭建说明和逐件下料、排料表。
- 总长510、总宽64.5、总高98毫米。冠部横杆与斜撑分置中央孔两侧；两片侧架各向内移动1毫米，单根木条截面和侧架形状不缩放。
- 228处有效胶接，另4处K/B微小擦触保持无胶。12根原料含切耗用6571毫米，仅余29毫米，须严格按表分料。

各方案模型、切口和下料表独立，不能混用留孔前的文件。中心20 × 20毫米是暂定所需净空，实际吊钩尺寸仍需量取并试穿；预留盒距离最近横杆只有0.75毫米名义余量。

全部木条截面为2.5 × 2.5毫米，原料为12根、每根550毫米，胶水限3克。屏幕图像不是1:1定位模板；轴线端点距离不等于毛坯长度。透明承压板和支架仅表示比赛器具，不计入木材或导出模型。

模型不包含胶厚与手工误差。实际承重取决于木材、胶水、接头、支承接触和制作质量；22克限重必须实称，排料满足原料总长不等于成品重量合格。
